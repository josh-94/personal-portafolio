Reference pattern. It does not describe a client.

SharePoint is a good place for the file: versions, library permissions, and a stable link. It gets awkward when the list also tries to be the case file, the board, and the audit of the process.

Leave the document and its link in the library. Leave status, owner, and date in Dataverse, or in the SQL system that already owns them. The flow [from a SharePoint item to a Dataverse row](/en/automations/sharepoint-to-dataverse) shows that split.
