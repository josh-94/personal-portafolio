Reference pattern. It does not describe a client.

Use it when the process has no previous master: the request, the case file, or the status is created in the app. Dataverse security roles decide who can see and who can approve. The table travels in the solution, so DEV, TEST, and PROD share the model.

Do not use it to clone a core system that already has an owner. In that case the link stores the external key and Dataverse stores only the transaction.
