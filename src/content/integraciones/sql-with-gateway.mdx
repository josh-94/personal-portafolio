Reference pattern. It does not describe a client.

The gateway is installed on the network where SQL already answers. Power Platform talks to the gateway; the gateway talks to the server. The database does not have to be published to the internet.

Before installing it, IT needs to know: which server hosts the gateway, which service account reads SQL, which table is queried, and whether writes are allowed. A gateway without an owner goes down in a patch and the app stops opening.

The guide [Dataverse or SQL Server](/en/guides/dataverse-or-sql-server) helps decide whether the master stays in SQL.
