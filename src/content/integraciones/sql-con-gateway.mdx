Patrón de referencia. No describe un cliente.

El gateway se instala en la red donde el SQL ya responde. Power Platform habla con el gateway; el gateway habla con el servidor. La base no tiene que publicarse en internet.

Antes de instalarlo, TI necesita saber: en qué servidor queda el gateway, con qué cuenta de servicio lee SQL, qué tabla se consulta y si la escritura está permitida. Un gateway sin dueño se apaga en un parche y la aplicación deja de abrir.

La guía [Dataverse o SQL Server](/guias/dataverse-o-sql-server) ayuda a decidir si el maestro se queda en SQL.
