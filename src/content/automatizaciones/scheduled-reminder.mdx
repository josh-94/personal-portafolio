Reference pattern. It does not describe a client.

The trigger is a schedule, not a click. Each run filters records that are due and still open. The notice goes out once per record. If the flow does not mark that it already notified, the next day it sends the mail again.

Keep the last run and the number of notices. If the flow fails on Monday, Tuesday shows it.
