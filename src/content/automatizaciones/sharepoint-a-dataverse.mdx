Patrón de referencia. No describe un cliente.

SharePoint guarda el archivo. Dataverse guarda el expediente: estado, responsable, vencimiento. El flujo crea la fila si no existe y actualiza la clave del ítem si ya existe. La clave es el id del ítem, no el nombre del archivo, porque el nombre cambia.

No copies todas las columnas. Copia las que el proceso consulta. El archivo sigue abriéndose desde SharePoint.
