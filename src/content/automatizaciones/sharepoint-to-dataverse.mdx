Reference pattern. It does not describe a client.

SharePoint keeps the file. Dataverse keeps the case file: status, owner, due date. The flow creates the row if it does not exist and updates the item key if it does. The key is the item id, not the file name, because the name changes.

Do not copy every column. Copy the ones the process looks up. The file still opens from SharePoint.
